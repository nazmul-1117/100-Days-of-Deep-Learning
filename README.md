# 🧠 Deep Learning Journey 2025

## 🚀 Overview

This repository documents my transition from traditional Machine Learning to Deep Learning, starting on **October 25, 2025**. It will contain all code, notes, projects, and experiments related to mastering Neural Networks, specialized architectures (CNNs, RNNs, Transformers), and popular frameworks like Keras/TensorFlow and PyTorch.

**Goal:** To build a solid practical and theoretical foundation in modern AI.
